# Полигон контейнерных поездов

## Расширение браузера — работа без интернета

**[Скачать расширение 1.2.0](https://github.com/KapunovKA/poligon/raw/refs/heads/main/extension/Poligon-extension-1.2.0.zip)** — для Chrome, Edge и Яндекс Браузера. Все библиотеки, шрифт PDF и легенда включены в архив.

1. Полностью распакуйте ZIP в постоянную папку.
2. Откройте `chrome://extensions` (Chrome), `edge://extensions` (Edge) или `browser://extensions` (Яндекс Браузер).
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Выберите папку `Poligon-extension`, в которой находится `manifest.json`.
5. Нажмите значок расширения — приложение откроется в отдельной вкладке.

Для обновления сохраните проект JSON, замените файлы в прежней папке и нажмите кнопку обновления на странице расширений. Удалять расширение не нужно. Подробная инструкция также находится внутри ZIP.

Данные сайта автоматически в расширение не переносятся: загрузите сохранённый JSON проекта и отдельно выберите подложку карты. Если организация запрещает установку расширений, обратитесь к системному администратору.

Веб-приложение: https://kapunovka.github.io/poligon/

Откройте ссылку в современном браузере, импортируйте Excel, выберите подложку карты и сформируйте таблицы. Установка расширения не нужна. Для локального запуска откройте index.html.

Данные хранятся только в локальном хранилище браузера. Между ПК они автоматически не синхронизируются: переносите проект JSON и изображение подложки. Публичный сайт содержит только программу, без пользовательских данных.

В режиме диапазона месяцев наведите курсор на число или перейдите к нему клавишей Tab: появится помесячная расшифровка количества поездов и среднего за сутки. Нулевые месяцы включены в расчёт. После смены периода нажмите «Обновить информацию».

PDF: текст и границы мини-таблиц сохраняются векторно со встроенным шрифтом Noto Sans Bold (SIL OFL, лицензия в libs/NotoSans-LICENSE.txt). Текст остаётся чётким при увеличении. Размер таблиц берётся из просмотра карты, а их суммарная площадь ограничена 18% площади подложки. Экспорт сохраняет заданные координаты без автоматического раздвигания; доступен выбор «Как на карте», «Увеличенные» и «Компактные». Текст остаётся векторным при любом размере. Подложка и легенда сохраняются без JPEG-сжатия. Изображение подложки сохраняет исходное разрешение в пределах 16000 пикселей по стороне и 80 млн пикселей; более крупные изображения уменьшаются. Качество исходной подложки и легенды ограничено исходными файлами. Легенда включена. В помесячной подсказке выделяются все месяцы с максимальным положительным количеством поездов.

В комплекте сохранена совместимость с расширением Chrome через manifest.json и app.html. Сторонние библиотеки находятся в libs/ с исходными уведомлениями об авторских правах.

## Сборка 1.2.0 — 05.11.2026

Номер версии и дата сборки отображаются в шапке приложения. Фильтры на вкладке «База данных» можно сочетать: тип, станции отправления и прибытия, их коды, год, месяц, минимальное и максимальное количество поездов. Поиск по всем полям дополняет выбранные условия. Все условия применяются одновременно (И); числовые тип, год и месяц сравниваются точно, названия и коды ищутся по части значения. Для станций доступны подсказки из загруженной базы. «Применить фильтры» или Enter запускают поиск; «Сбросить всё» очищает условия. Показано число найденных записей, блок фильтров можно свернуть.
