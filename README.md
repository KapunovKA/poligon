# Полигон контейнерных поездов

Веб-приложение: https://kapunovka.github.io/poligon/

Откройте ссылку в современном браузере, импортируйте Excel, выберите подложку карты и сформируйте таблицы. Установка расширения не нужна. Для локального запуска откройте index.html.

Данные хранятся только в локальном хранилище браузера. Между ПК они автоматически не синхронизируются: переносите проект JSON и изображение подложки. Публичный сайт содержит только программу, без пользовательских данных.

В режиме диапазона месяцев наведите курсор на число или перейдите к нему клавишей Tab: появится помесячная расшифровка количества поездов и среднего за сутки. Нулевые месяцы включены в расчёт. После смены периода нажмите «Обновить информацию».

PDF: таблицы рисуются напрямую на Canvas, без последовательных html2canvas-снимков. Максимальная сторона изображения PDF — 5000 пикселей; при уменьшении очень больших подложек возможна потеря мелких деталей. Сохранена автоматическая разводка таблиц. В архиве не было legend.png — легенду можно добавить этим файлом.

В комплекте сохранена совместимость с расширением Chrome через manifest.json и app.html. Сторонние библиотеки находятся в libs/ с исходными уведомлениями об авторских правах.
